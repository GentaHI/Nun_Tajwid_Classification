# Nun_Tajwid_Classification
Klasifikasi audio hukum tawid nun sukun atau tanwin dengan struktur deep learning dasar

## Requirement di system-level

rubberband-cli == 2.0.0-2 (still in this version up until June 2025)

Cara Instal pada debian/ubuntu OS:
```
apt-get install rubberband-cli
```

Cara Instal pada Windows OS:
- Ke website resmi Rubber Band [disini](https://breakfastquay.com/rubberband/)
- Cari dan klik **Rubber Band Library v4.0.0 command-line utility**, atau klik [Link](https://breakfastquay.com/files/releases/rubberband-4.0.0-gpl-executable-windows.zip)

## Requirements Python Package

librosa == 0.10.2.post1  
matplotlib ~= 3.2  
numpy == 2.0.1  
seaborn ~= 0.15  
scikit-learn == 1.5.0  
pyrubberband == 0.4.0  
soundfile >= 0.12.1
